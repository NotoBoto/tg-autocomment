# TG Автокомментатор

Окно-приложение, которое следит за Telegram-каналами и на каждый новый пост
готовит комментарий: текст пишет нейросеть (Claude, Gemini или ChatGPT — по подписке
или по API-ключу), картинка берётся из вашей папки. Можно комментировать сразу
с нескольких аккаунтов. Вы проверяете и публикуете в один клик — или включаете
полностью автоматический режим. Работает в фоне, запускается вместе с Windows и обновляется сама.

## Возможности

- Все настройки, промпт и журнал — в одном окне, без правки файлов руками
- Можно следить сразу за несколькими каналами, в том числе закрытыми, — у каждого поста в очереди видно, откуда он
- Несколько аккаунтов Telegram одновременно: каждый — отдельный профиль со своими каналами,
  промптом, нейросетью, картинками и режимом. Все профили с «Запускать со всеми» стартуют
  общей кнопкой «▶ Запустить» и комментируют независимо; очередь общая, у поста видно, от чьего он имени
- Вход в Telegram прямо в программе: по QR-коду или по номеру телефона (+ 2FA)
- Очередь постов: комментарий можно **поправить**, **перегенерировать с пожеланием**
  («покороче», «разгон 4»…), **сменить картинку** или **пропустить пост**
- Кнопка «Взять последний пост канала» — проверить промпт, не дожидаясь нового поста
  (пост берёт аккаунт, выбранный в строке «Аккаунт», и пишет комментарий по его промпту;
  если каналов несколько — рядом выбор, из какого). Стоп-слова здесь не проверяются
- **Пост по ссылке** — поле над очередью: вставьте ссылку на любой пост (`t.me/канал/123`,
  в Telegram — «Копировать ссылку»), и комментарий к нему появится в очереди. Канал не обязательно
  должен быть в списке; закрытый (`t.me/c/…`) — если аккаунт в нём состоит. Если под постом выключены
  комментарии, программа скажет об этом сразу, не тратя запрос к нейросети
- Один пост можно комментировать сколько угодно раз: каждое «Взять» (по ссылке или последний пост) —
  новый вариант в очереди, даже если ваш комментарий там уже есть. Сама по себе, в автоматическом
  режиме, программа комментирует каждый пост только один раз
- Семь способов подключения к нейросети на выбор:
  - **Claude Code** — по подписке Claude Pro/Max, без оплаты за запросы
  - **Antigravity (Google)** — модели Gemini через Antigravity CLI и вход в Google-аккаунт, ключ не нужен
    (Gemini CLI с 18.06.2026 не работает с личными аккаунтами — Antigravity его замена)
  - **Claude API** — ключ Anthropic, оплата по токенам; большой промпт кэшируется
  - **Gemini API** — ключ Google AI Studio, есть бесплатный лимит
  - **ChatGPT (Codex)** — через Codex CLI и аккаунт ChatGPT с любым тарифом, включая бесплатный
    (лимиты зависят от тарифа: на Free и Go маленькие, для постоянной работы лучше Plus и выше), ключ не нужен
  - **OpenAI API** — ключ platform.openai.com, оплата по токенам
  - **Своя модель** — любая модель на OpenAI-совместимом сервере: локально (LM Studio, Ollama,
    llama.cpp, vLLM — бесплатно и без интернета) или в облаке (OpenRouter, DeepSeek и т. п.)

  Для Claude Code, Antigravity и Codex программа сама устанавливает нужное и открывает вход
  кнопкой «Установить и войти». Расход токенов по API виден в «Журнале»
- Нейронка может смотреть картинки поста (фото, превью видео)
- Пропуск постов на тяжёлые темы: посты со стоп-словами пропускаются сразу, а ещё модель
  может ответить SKIP — в автоматическом режиме такой пост пропускается, при ручном
  подтверждении попадает в очередь с пометкой (можно перегенерировать или пропустить)
- **Моментальная публикация** в автоматическом режиме: под новым постом сразу появляется заготовка
  из вашего списка, чтобы комментарий оказался среди первых, а потом её текст заменяется комментарием нейросети
- Картинки идут «колодой» без повторов, альбомы склеиваются в один пост
- Если Telegram просит подождать (FloodWait) до 5 минут — программа ждёт и повторяет
- Перед запросом к нейросети программа проверяет, можно ли писать в обсуждении: если аккаунт там
  забанен, писать могут только участники группы или только админы — пост пропускается сразу,
  а в «Журнале» видно почему. Медленный режим группы до 5 минут программа выжидает; если
  в обсуждении запрещены картинки — публикует комментарий без картинки, а если без картинки писать
  нельзя — прикладывает её всегда, независимо от «Прикладывать картинку»
- Работает через VPN в любом режиме (TUN или «системный прокси»), можно задать свой прокси
  для каждого аккаунта: SOCKS5, HTTP или MTProxy
- Работает в фоне: крестик прячет окно в трей (как Telegram), значок показывает статус,
  а о новом посте в очереди придёт уведомление Windows
- Автозапуск вместе с Windows: сразу в трей и через 30 секунд — начало работы
- Автообновление: новые версии скачиваются и ставятся сами, работа после этого продолжается

## Установка

1. Скачайте **`TG-Autocomment-…-Setup.exe`** со страницы
   [Releases](https://github.com/NotoBoto/tg-autocomment/releases/latest) и запустите.
2. Windows может показать синее окно **«Windows защитила ваш компьютер»** — установщик не подписан
   платным сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. «Далее» → «Установить». По желанию — галочки «Ярлык на рабочем столе» и «Запускать вместе
   с Windows». Права администратора не нужны, Python и библиотеки — тоже: всё внутри.

Где что лежит:

- программа — `%LOCALAPPDATA%\Programs\TG Autocomment`;
- настройки, промпты, сессии Telegram, журнал (`log.txt`) — `%APPDATA%\TG Autocomment`.
  Обновления и переустановка их не трогают.

Удаление — «Параметры» → «Приложения» → «TG Автокомментатор». Программа спросит, стирать ли
настройки и сессии: «Нет» — при повторной установке не придётся заново всё настраивать и входить.

### Обновления

Программа обновляется сама:

- проверяет новую версию на GitHub через 15 секунд после запуска и дальше раз в 6 часов;
- если новая версия есть и ничего не прервётся (очередь пуста — в том числе нет комментариев
  с таймером автопубликации, ничего не пишется, промпт сохранён, не идёт вход в Telegram) — скачивает её,
  сверяет контрольную сумму, ставит и перезапускается. Снова запускаются только те аккаунты, которые
  работали до обновления (остановленные вручную так и остаются остановленными); если окно было
  в трее — программа вернётся в трей;
- если прерывать нельзя — сверху окна появляется полоса «Доступна новая версия» с кнопками
  «Обновить сейчас» и «Что нового», а обновление повторится при следующей проверке;
- если установщик не запустился (например, его удалил антивирус) — программа продолжит работать
  как была, а в полосе будет «Не удалось установить обновление» и кнопка «Повторить».

Выключить автоустановку — «Настройки» → «Программа» → «Устанавливать обновления автоматически»:
тогда о новой версии сообщит та же полоса. Там же — номер текущей версии (он есть и в шапке окна)
и кнопка «Проверить обновления».

### Запуск из исходников

Скачать код и дважды щёлкнуть **`start.bat`**: нет Python — поставит через `winget`, нет библиотек —
поставит при первом запуске (вручную: `pip install -r requirements.txt`, затем `python app.py`).
В этом режиме данные лежат рядом с `app.py`, а об обновлениях программа только сообщает
(кнопка «Скачать» ведёт на страницу релиза).

## Первый запуск

Программа откроет вкладку «Настройки» с подсказками:

1. **Нейросеть** — выбрать способ подключения:
   - для «Claude API» / «Gemini API» / «OpenAI API» — вставить ключ (console.anthropic.com,
     aistudio.google.com или platform.openai.com) и нажать «Проверить ключ»;
   - для «Claude Code», «ChatGPT (Codex)» и «Antigravity (Google)» — **«Установить и войти»**:
     программа сама скачает нужное официальным установщиком (для Codex — ещё Node.js, если его нет)
     и откроет вход в браузере. Статус обновится сам;
   - для «Своя модель» — см. раздел «Своя модель (LM Studio, Ollama…)» ниже.
2. **API ID** и **API Hash** — в установленной программе указывать **не нужно**: в неё встроен свой ключ.
   Свой можно взять на https://my.telegram.org → API development tools (один подходит для всех ваших
   аккаунтов) — тогда программа будет работать с ним. При запуске из исходников без собранного ключа
   (см. «Выпуск новых версий») поля обязательны. Если у аккаунта уже есть вход с одним ключом,
   после смены ключа Telegram может попросить войти заново. Если Telegram не примет ключ, окно входа
   так и скажет: свой — проверить или очистить поля, встроенный — обновить программу или указать свой
3. **Каналы** — по одному на строку: `username`, `@username` или ссылка `t.me/username`
   (можно и ссылку на пост). **Закрытый канал** — ссылка-приглашение `t.me/+…` или ссылка на любой
   его пост `t.me/c/…` («Копировать ссылку» в Telegram); аккаунт должен уже состоять в канале — сама
   программа никуда не вступает, а в «Журнале» подскажет, если аккаунт в канале не состоит
4. Вкладка **«Промпт»** — инструкция для нейросети
5. **▶ Запустить** — откроется окно входа в Telegram (один раз для каждого аккаунта)
6. Нужны ещё аккаунты — «+ Добавить аккаунт» в строке «Аккаунт» (см. ниже)

## Как пользоваться

- **Подтверждать вручную** — каждый комментарий появляется во вкладке «Очередь».
  Окно подаст звук, а в заголовке будет число ожидающих.
- **Публиковать сами** — комментарии уходят автоматически. Как именно — «Настройки» →
  «Автоматический режим» → «Публикация»:
  - **С задержкой** — нейросеть пишет комментарий, и он уходит после случайной паузы (настраивается).
    Пока пауза идёт, комментарий виден в «Очереди» с обратным отсчётом: его можно поправить, сменить
    картинку, **добавить время** (+5 мин, +15 мин, +1 час или своё — минуты `20` или часы:минуты `1:30`),
    **опубликовать сейчас** или **отменить публикацию**. Переключились на «Подтверждать вручную» — такие
    комментарии снимаются с таймера и ждут вашего решения;
  - **Моментально** — под новым постом сразу появляется заготовка (список своих фраз, берётся случайная),
    чтобы комментарий оказался среди первых. Когда нейросеть напишет настоящий, текст заготовки
    заменится им — в Telegram у комментария будет пометка «изменено». Если нейросеть ответит SKIP
    (тяжёлая тема), заготовка удаляется, а если нейросеть не ответила — остаётся как есть.

  Что происходит — во вкладке «Журнал».

Режим и «Нейронка смотрит картинки поста» переключаются на лету и запоминаются (у каждого профиля свои).

**Несколько аккаунтов.** Строка «Аккаунт» над вкладками: «+ Добавить аккаунт» копирует настройки
и промпт текущего профиля — поменяйте, что нужно, и нажмите «▶ Запустить только этот», чтобы войти
в новый аккаунт, не останавливая остальные. Вкладки «Настройки» и «Промпт» показывают профиль,
выбранный в этой строке. Вход в Claude Code / Codex / Antigravity общий для всех профилей —
он один на компьютер.

**Трей.** Крестик не закрывает программу, а прячет её в трей (область у часов; если значка не видно —
он под стрелкой «^»). Цвет значка: серый — остановлено, оранжевый — подключение или нужен вход,
зелёный — работает. Щелчок — открыть окно, правая кнопка — «Запустить/Остановить» и **«Выход»**.
Когда окно в трее, о новом посте в очереди и о том, что аккаунту нужен вход, приходит уведомление Windows.
Чтобы крестик закрывал программу, выключите «Настройки» → «Программа» → «При закрытии окна сворачивать в трей».
При выходе программа предупредит, если в очереди есть непроверенные комментарии, комментарии
с таймером автопубликации или такие, что ещё пишутся, — после выхода они не уйдут.
В моментальном режиме заготовка к этому времени уже опубликована — после выхода она так и останется
заготовкой, без замены на комментарий нейросети.

**Автозапуск.** «Настройки» → «Программа» → «Запускать вместе с Windows» (или галочка в установщике).
После входа в Windows программа откроется сразу в трее, а через 30 секунд (время на подключение VPN
и сети) сама запустит аккаунты с «Запускать со всеми». Если аккаунт не настроен — он пропускается,
причина в «Журнале»; если нужен вход в Telegram — окно откроется само. При запуске из исходников:
перенесли папку — запустите программу один раз вручную, путь в автозапуске обновится.

Вторая копия программы не запускается: повторный запуск просто показывает окно уже работающей.

## Своя модель (LM Studio, Ollama…)

Можно писать комментарии своей нейросетью — на этом компьютере (бесплатно, без интернета и VPN)
или в облаке у любого сервиса с OpenAI-совместимым API. «Настройки» → «Нейросеть» → **«Своя модель»**:

1. Запустите сервер с моделью:
   - **LM Studio** — скачайте модель, загрузите её и включите сервер: вкладка «Developer» → «Start Server»;
   - **Ollama** — установите, скачайте модель (`ollama pull qwen3:8b`), программа Ollama должна быть запущена;
   - **llama.cpp / vLLM** — `llama-server` или `vllm serve` со своей моделью.
2. **Адрес сервера** — кнопки «LM Studio» (`http://localhost:1234/v1`) и «Ollama»
   (`http://localhost:11434/v1`) подставят его сами; для другого сервера — его адрес, обычно с `/v1` на конце.
   Сервер на другом компьютере в сети — `http://192.168.…:порт/v1`.
3. **API-ключ** — локальным серверам не нужен; для облачных (OpenRouter, DeepSeek…) — ключ сервиса.
4. **«Проверить подключение»** — подгрузит список моделей сервера, выберите нужную.

Что важно знать:

- **Длина контекста.** Промпт с инструкцией большой, а LM Studio и Ollama по умолчанию дают модели
  маленький контекст (около 4 тыс. токенов). Поставьте **16–32 тыс. и больше**: в LM Studio — в настройках
  модели «Context Length», в Ollama — параметр `num_ctx`. Иначе программа сообщит «Промпт не помещается
  в контекст модели».
- **Картинки поста** («Нейронка смотрит картинки») понимают только модели с vision (Gemma 3, Qwen2.5-VL,
  LLaVA и т. п.); с обычной моделью это переключатель лучше выключить.
- **Скорость** зависит от компьютера: на слабой видеокарте ответ может идти минуту и дольше — тогда
  увеличьте «Таймаут ответа».
- «Размышления» моделей вроде DeepSeek-R1 и Qwen3 (`<think>…</think>`) из ответа вырезаются сами.
  Если ответ оборвался посреди размышлений, программа его не опубликует и подскажет увеличить лимит
  длины ответа и контекст модели.
- К серверу на этом компьютере или в локальной сети программа ходит **мимо VPN-прокси**, к облачным —
  как обычно, через системный прокси.

## Если Telegram или нейросети заблокированы (VPN и прокси)

Telegram в России, а Claude, ChatGPT и Gemini — в России и ряде других стран без VPN не работают.
Настройка — «Настройки» → «Telegram» → **«Прокси»** (у каждого аккаунта своя):

- **Системный (из VPN)** — по умолчанию. Подходит VPN-клиент в любом режиме:
  - **TUN / «VPN-режим»** (WireGuard, AmneziaVPN, v2rayN/Hiddify/Happ в режиме TUN) — весь трафик
    и так идёт через VPN;
  - **Proxy / «системный прокси»** — программа сама берёт адрес прокси из настроек Windows
    и пускает через него Telegram и нейросети. Под полем видно, какой прокси найден.

  VPN нужно включить **до** запуска аккаунта; включили позже — остановите и запустите аккаунт заново.
- **Свой** — адрес прокси только для Telegram этого аккаунта: `socks5://127.0.0.1:10808`,
  `http://host:port`, `socks5://логин:пароль@host:port` или ссылка `t.me/proxy?…` (MTProxy).
  Так можно дать разным аккаунтам разные IP. MTProxy с секретом `ee…` (FakeTLS) не поддерживается.
- **Без прокси** — напрямую, даже если в Windows задан системный прокси.

Не подходят: VPN-расширение в браузере (работает только для браузера) и раздельное туннелирование
«только заблокированные сайты» по доменам — программа подключается к Telegram по IP-адресам.

Claude Code, Codex и Antigravity понимают только HTTP-прокси. Если VPN-клиент даёт системный прокси
SOCKS — для них включите режим TUN (способы по API-ключу работают и через SOCKS).
Своей модели на этом компьютере или в локальной сети VPN не нужен.

Вход в Claude Code, Codex и Antigravity из страны, где они не работают, не пройдёт. Поэтому, если
системный HTTP-прокси не найден, программа перед входом предупредит: включите VPN (сервер в США
или Европе) — или нажмите «ОК», если VPN уже работает в режиме TUN.

Не подключается — смотрите «Журнал»: там написано, напрямую или через какой прокси шло подключение.

Ошибка нейросети вида «not available in your location» / «location is not supported» значит,
что сервис видит страну, где он не работает: запрос ушёл мимо VPN или сервер VPN стоит в такой
стране. Программа подскажет, шли ли запросы через прокси. Помогает VPN с сервером в США или Европе
(режим TUN или системный HTTP-прокси); если нет — другой сервер VPN или другой способ подключения.

## ⚠️ Важно

- Файлы `*.session` (`my_account.session`, `account_….session` у добавленных профилей; в установленной
  версии — в `%APPDATA%\TG Autocomment`) — это полный доступ к аккаунтам Telegram. Никому не передавайте.
  При удалении профиля программа предложит удалить и его файл сессии.
- В режимах по подписке (Claude Code, ChatGPT/Codex) программа убирает `ANTHROPIC_API_KEY`
  и `OPENAI_API_KEY` из окружения, чтобы запросы не ушли на платный API.
  В режимах по API-ключу, если поле ключа пустое, берётся ключ из переменной окружения
  (`ANTHROPIC_API_KEY`, `GEMINI_API_KEY` / `GOOGLE_API_KEY`, `OPENAI_API_KEY`).
- Telegram может ограничить аккаунт за автоматические комментарии —
  лучше использовать отдельный аккаунт. Если несколько аккаунтов комментируют одни и те же
  посты, задайте им разные промпты и паузы, чтобы комментарии не выглядели одинаковыми.
  В моментальном режиме пауз нет — дайте аккаунтам разные заготовки, а лучше включайте его только
  у одного-двух аккаунтов: одновременные комментарии с нескольких аккаунтов в первые секунды заметны.
  Если Telegram ограничил или заморозил аккаунт, в «Журнале» будет сказано об этом и предложено
  узнать подробности у @SpamBot.
- Старый `config.json` с одним аккаунтом при первом запуске сам превращается в профиль «Основной».
- Переходите с запуска из исходников на установщик? Скопируйте `config.json`, `prompt*.txt`, `*.session`
  и `done_posts_*.txt` из папки с `app.py` в `%APPDATA%\TG Autocomment` — тогда не придётся заново
  настраивать программу и входить в Telegram.

## Выпуск новых версий (для разработчика)

Сборка запускается **только тегом**: обычные коммиты и пуши в `main` ничего не публикуют
и пользователям не приходят.

1. Поменять номер в `core.py`: `VERSION = "0.1.1"`.
2. Описать изменения в `RELEASE_NOTES.md` — текст попадёт на страницу релиза и в кнопку
   «Что нового» в программе.
3. Закоммитить, запушить и поставить тег с тем же номером:
   ```bash
   git tag v0.1.1
   git push origin v0.1.1
   ```
4. Через ~5 минут GitHub Actions (`.github/workflows/release.yml`) соберёт установщик и опубликует
   релиз с файлом `TG-Autocomment-0.1.1-Setup.exe`. Если номер в `core.py` не совпадает с тегом,
   сборка остановится с ошибкой и ничего не опубликует.

Установленные программы увидят релиз при следующей проверке — то есть в течение ~6 часов
или при следующем запуске — и обновятся сами (см. «Обновления»).

**Номера версий:** исправления — `0.1.1`, `0.1.2`; новые возможности — `0.2.0`; когда программа
устоится — `1.0.0`. Автообновление ставит только версию с номером **больше** установленной.

**Проверить сборку до выпуска.** Опубликованная версия сразу уходит всем с автообновлением, поэтому
перед тегом удобно собрать установщик без публикации: GitHub → «Actions» → «Release» → «Run workflow».
Готовый установщик появится в артефактах этой сборки (`setup`) — его можно скачать и проверить.

**Если релиз оказался неудачным** — выпустите исправленную версию со следующим номером (например,
`0.1.2`): откатиться автоматически программа не может, удаление релиза тоже не вернёт тех, кто уже
обновился.

**Собрать локально:** `pip install -r requirements.txt pyinstaller`, затем `python build.py`
(нужен Inno Setup 6) или `python build.py --no-setup` — только программа в `dist\TG Autocomment`,
без установщика.

**Встроенный ключ Telegram.** Чтобы пользователям не нужно было получать API ID и Hash, программа
собирается со своим ключом. В репозитории его нет:

1. Один раз получите ключ на https://my.telegram.org → API development tools.
2. GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   `TG_API_ID` (число) и `TG_API_HASH` (32 символа). Без них релиз по тегу не соберётся.
3. Локально — задайте те же переменные окружения перед `python build.py`; для запуска из исходников
   хватит `python build.py --key-only`. В PowerShell удобно так: скопировать API Hash в буфер обмена
   и выполнить в папке проекта (API ID спросит, hash возьмёт из буфера и потом очистит его):
   ```powershell
   $env:TG_API_ID = Read-Host "API ID"; $env:TG_API_HASH = (Get-Clipboard -Raw).Trim(); python build.py --key-only; Remove-Item Env:TG_API_ID, Env:TG_API_HASH; Set-Clipboard -Value " "
   ```
   В случае ошибки `build.py` скажет, какое из значений не подходит, не показывая сами значения.

`build.py` записывает ключ в `_builtin_api.py` (он в `.gitignore`) в замаскированном виде — так его
не найти поиском строк в `.exe`. Полностью спрятать ключ нельзя: программа сама отправляет его
Telegram, и разобравший `.exe` его достанет. Это ключ приложения, а не доступ к аккаунтам: с ним
нельзя войти ни в чей Telegram, худшее — Telegram заблокирует ключ, если его используют для спама.
Тогда получите новый, обновите секреты и выпустите новую версию — автообновление разнесёт её всем.
