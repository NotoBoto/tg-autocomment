# TG Autocomment

Следит за Telegram-каналом и на каждый новый пост оставляет комментарий:
текст генерирует Claude (через Claude Code по подписке), картинка берётся
случайно из папки `images/`.

## Возможности

- Комментарий от вашего аккаунта в обсуждении под постом
- Генерация через `claude -p` — без API-ключа, по подписке Pro/Max
- Опционально: нейронка видит картинки из поста (фото, превью видео)
- Режим с ручным подтверждением или полностью автоматический
- Пропуск постов на тяжёлые темы (стоп-слова + проверка моделью)
- Картинки идут «колодой» без повторов, альбомы склеиваются в один пост

## Установка

1. Python 3.10+ и Node.js
2. Claude Code:
   ```
   npm install -g @anthropic-ai/claude-code
   claude
   ```
   (войти под аккаунтом с подпиской, затем `/exit`)
3. Зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Скопировать примеры и заполнить:
   ```
   copy config.example.json config.json
   copy prompt.example.txt prompt.txt
   ```
   `api_id` и `api_hash` — с https://my.telegram.org (API development tools)
5. Положить картинки в `images/`

## Запуск

```
python main.py
```

При первом запуске Telegram попросит номер и код. Если код не приходит:

```
python login_qr.py
```

и отсканировать QR в Telegram → Настройки → Устройства → Подключить устройство.

## Настройки (`config.json`)

| Поле | Что делает |
|---|---|
| `channel` | username канала без `@` |
| `model` | `sonnet`, `opus` или `haiku` |
| `confirm_before_post` | режим по умолчанию при запуске |
| `send_post_images` | передавать картинки поста по умолчанию |
| `max_post_images` | сколько картинок поста передавать максимум |
| `delay_min_sec` / `delay_max_sec` | задержка в автоматическом режиме |
| `skip_keywords` | стоп-слова для пропуска постов |

## ⚠️ Важно

- Файл `*.session` — это полный доступ к аккаунту Telegram. Никому не передавайте.
- `ANTHROPIC_API_KEY` в окружении не нужен — программа его убирает, чтобы
  не списывались деньги по API.
- Telegram может ограничить аккаунт за автоматические комментарии —
  лучше использовать отдельный аккаунт.
