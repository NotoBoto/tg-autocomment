# TG Автокомментатор

Окно-приложение, которое следит за Telegram-каналом и на каждый новый пост
готовит комментарий: текст пишет Claude (через Claude Code по подписке), картинка
берётся из вашей папки. Вы проверяете и публикуете в один клик — или включаете
полностью автоматический режим.

## Возможности

- Все настройки, промпт и журнал — в одном окне, без правки файлов руками
- Вход в Telegram прямо в программе: по QR-коду или по номеру телефона (+ 2FA)
- Очередь постов: комментарий можно **поправить**, **перегенерировать с пожеланием**
  («покороче», «разгон 4»…), **сменить картинку** или **пропустить пост**
- Кнопка «Взять последний пост канала» — проверить промпт, не дожидаясь нового поста
- Шесть способов подключения к нейросети на выбор:
  - **Claude Code** — по подписке Claude Pro/Max, без оплаты за запросы
  - **Antigravity (Google)** — модели Gemini через Antigravity CLI и вход в Google-аккаунт, ключ не нужен
    (Gemini CLI с 18.06.2026 не работает с личными аккаунтами — Antigravity его замена)
  - **Claude API** — ключ Anthropic, оплата по токенам; большой промпт кэшируется
  - **Gemini API** — ключ Google AI Studio, есть бесплатный лимит
  - **ChatGPT (Codex)** — по подписке ChatGPT Plus/Pro/Business через Codex CLI, ключ не нужен
  - **OpenAI API** — ключ platform.openai.com, оплата по токенам

  Для Claude Code, Antigravity и Codex программа сама устанавливает нужное и открывает вход
  кнопкой «Установить и войти». Расход токенов по API виден в «Журнале»
- Нейронка может смотреть картинки поста (фото, превью видео)
- Пропуск постов на тяжёлые темы (стоп-слова + проверка моделью)
- Картинки идут «колодой» без повторов, альбомы склеиваются в один пост
- Если Telegram просит подождать (FloodWait) до 5 минут — программа ждёт и повторяет

## Установка и запуск

Дважды щёлкнуть **`start.bat`** — больше ничего ставить вручную не нужно:

- нет Python → `start.bat` установит его через `winget` (встроен в Windows 10/11);
- нет библиотек → установит их при первом запуске;
- для «Claude API» / «Gemini API» / «OpenAI API» ничего ставить не нужно: вставить ключ
  (console.anthropic.com, aistudio.google.com или platform.openai.com) и нажать «Проверить ключ»;
- для «ChatGPT (Codex)» — «Установить и войти»: поставит Node.js (если нет) и Codex CLI,
  затем откроет вход в аккаунт ChatGPT;
- для «Antigravity (Google)» — «Установить и войти»: поставит Antigravity CLI официальным
  установщиком и откроет вход через Google;
- для «Claude Code», если его нет → в окне: «Настройки» → **«Установить и войти»**. Программа скачает
  Claude Code официальным установщиком (Node.js не нужен) и откроет вход в браузере.
  Войдите в аккаунт Claude с подпиской Pro/Max — статус обновится сам.

(Вручную: `pip install -r requirements.txt`, затем `python app.py`.)

При первом открытии программа покажет вкладку «Настройки» с подсказками:

1. **Claude** — «Установить и войти» (или «Войти в Claude», если уже установлен)
2. **API ID** и **API Hash** — с https://my.telegram.org → API development tools
3. **Канал** — можно вставить `@username` или ссылку `t.me/...`
4. Вкладка **«Промпт»** — инструкция для нейросети
5. **▶ Запустить** — откроется окно входа в Telegram (один раз)

## Как пользоваться

- **Подтверждать вручную** — каждый комментарий появляется во вкладке «Очередь».
  Окно подаст звук, а в заголовке будет число ожидающих.
- **Публиковать сами** — комментарии уходят автоматически со случайной паузой
  (настраивается). Что происходит — во вкладке «Журнал».

Режим и «Нейронка смотрит картинки поста» переключаются на лету и запоминаются.

## ⚠️ Важно

- Файл `*.session` — это полный доступ к аккаунту Telegram. Никому не передавайте.
- `ANTHROPIC_API_KEY` в окружении не нужен — программа его убирает, чтобы
  не списывались деньги по API.
- Telegram может ограничить аккаунт за автоматические комментарии —
  лучше использовать отдельный аккаунт.
