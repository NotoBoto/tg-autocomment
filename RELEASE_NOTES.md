## Изменения в 0.5.15

- **Новые посты замечаются быстрее при «Моментально».** О постах крупных каналов Telegram сообщает
  с опозданием — бывает, до минуты, и заготовка уходила не первой. Теперь в «Настройки» →
  «Автоматический режим» → «Моментально» есть переключатель «Не ждать уведомлений Telegram — проверять
  каналы самим каждые 3 сек»: программа сама раз в несколько секунд одним запросом проверяет все каналы
  и берёт новый пост, не дожидаясь уведомления. Интервал можно поменять. По умолчанию выключено.
  Проверяются только каналы, на которые аккаунт подписан. В журнале у поста, найденного проверкой,
  пометка «нашла проверка». Если Telegram попросит подождать — увеличьте интервал.

**Установка:** скачайте `TG-Autocomment-0.5.15-Setup.exe` ниже. У кого уже стоит программа — она обновится
сама (когда нет незаконченных комментариев), настройки и сессии сохранятся.
