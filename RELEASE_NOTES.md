Первый публичный выпуск TG Автокомментатора — программы, которая следит за Telegram-каналами
и готовит комментарии к новым постам с помощью нейросети.

**Установка:** скачайте `TG-Autocomment-0.1.0-Setup.exe` ниже и запустите. Если Windows покажет
«Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (установщик не подписан
платным сертификатом). Python ставить не нужно.

## Что умеет

- Несколько каналов и несколько аккаунтов Telegram одновременно — у каждого аккаунта свои настройки и промпт
- Шесть способов подключения к нейросети: Claude Code, ChatGPT (Codex) и Antigravity по подписке
  или Claude / OpenAI / Gemini API по ключу
- Ручное подтверждение (поправить, перегенерировать с пожеланием, сменить картинку) или полностью автоматический режим
- Работа через VPN в любом режиме и свой прокси для каждого аккаунта (SOCKS5, HTTP, MTProxy)
- Работа в фоне: трей, уведомления, автозапуск вместе с Windows
- Автообновление: новые версии ставятся сами, когда очередь пуста

Подробности — в [README](https://github.com/NotoBoto/tg-autocomment#readme).
