## Изменения в 0.5.13

- **Проверка обновлений.** На части компьютеров она падала с ошибкой `CERTIFICATE_VERIFY_FAILED` —
  в Windows не находился нужный сертификат для GitHub. Теперь программа носит сертификаты с собой.
  Если у вас была эта ошибка, один раз скачайте установщик ниже вручную — дальше обновления пойдут сами.

**Установка:** скачайте `TG-Autocomment-0.5.13-Setup.exe` ниже. У кого уже стоит программа — она обновится
сама (когда нет незаконченных комментариев), настройки и сессии сохранятся.
