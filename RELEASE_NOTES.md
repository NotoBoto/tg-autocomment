## Изменения в 0.5.2

- **Список каналов применяется без перезапуска.** Добавили или убрали канал у запущенного аккаунта — после
  «Сохранить» программа сразу начинает (или перестаёт) следить за ним. Ищутся только новые каналы, поэтому
  сохранение занимает доли секунды, а посты в очереди никуда не деваются.
- **Понятное предупреждение о перезапуске.** Если у запущенного аккаунта поменяли API ID, API hash, файл сессии
  или прокси, рядом с кнопкой «Сохранить» появится красная надпись: нужен перезапуск («Остановить» → «Запустить»)
  и какие настройки он применит. Сама она не исчезает — пропадёт, когда аккаунт остановят.

**Установка:** скачайте `TG-Autocomment-0.5.2-Setup.exe` ниже. У кого уже стоит программа — она обновится
сама (когда нет незаконченных комментариев), настройки и сессии сохранятся.
